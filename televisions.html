DATA STORY

A bigger picture of TV energy.

This visualisation is designed for Australian households and TV shoppers who want to understand how screen size and technology relate to labelled annual energy use before comparing products.

01 / WHAT IS AVAILABLE

LCD (LED) dominates this dataset.

It accounts for 3,819 of 4,724 records, or 80.8%. The chart describes the supplied dataset and should not be read as an Australian sales share.

02 / THE MAIN PATTERN

Larger screens tend to use more energy.

The scatter plot shows a strong upward relationship between screen size and labelled annual energy. Use the filters to see whether the pattern remains within a brand or technology.

03 / THE FAIR COMPARISON

Technology needs context.

Median and box plots summarise each technology, but the groups contain different screen sizes. Compare them with the scatter plot before drawing a conclusion about efficiency.

Start with the two count charts, then follow the story through typical energy, distribution and screen size. Each chart labels its own unit so record counts are not confused with kWh/year.
